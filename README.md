# 🎰 Casino Platform

Plataforma SaaS para la creación y comercialización de juegos de casino modernos.

## 🏗️ Estructura del Proyecto

- **`game-engines/`**: Motores de juego (PixiJS, Three.js).
- **`backend/`**: API RESTful con Node.js/Express y MongoDB.
- **`admin-panel/`**: Dashboard para crear juegos con IA.
- **`client-sdk/`**: SDK para integración con sistemas de terceros.
- **`docs/`**: Documentación de la API y guías.
